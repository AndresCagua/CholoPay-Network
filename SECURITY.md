# Security policy

CholoPay is a local educational simulation and must never receive real credentials, payment data, identity documents, or production secrets.

Report suspected vulnerabilities privately to the repository maintainers before public disclosure. Include reproduction steps, affected component, and impact; redact all personal data. Do not test against systems you do not own.

Security boundaries and assumptions are documented in `docs/security-threat-model.md`. This project makes no claim of PCI DSS, ISO 27001, banking, or regulatory compliance.
