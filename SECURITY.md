# Política de seguridad

CholoPay es una simulación educativa local y nunca debe recibir credenciales reales, datos de pago, documentos de identidad ni secretos de producción.

Informa en privado las vulnerabilidades sospechadas a las personas mantenedoras del repositorio antes de divulgarlas públicamente. Incluye pasos de reproducción, componente afectado e impacto; redacta todos los datos personales. No pruebes contra sistemas que no te pertenezcan.

Los límites y supuestos de seguridad están documentados en `docs/security-threat-model.md`. Este proyecto no afirma cumplir PCI DSS, ISO 27001, requisitos bancarios ni regulatorios.
