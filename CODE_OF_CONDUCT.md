# Código de conducta

Se espera que las personas contribuidoras sean respetuosas, constructivas e inclusivas. Las referencias culturales de este proyecto educativo no deben presentarse como representación oficial de ninguna comunidad o institución. No se aceptan acoso, discriminación, doxxing ni la divulgación de datos personales o financieros reales.

Informa en privado las inquietudes sobre conducta a las personas mantenedoras.
